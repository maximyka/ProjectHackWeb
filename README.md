# Развёртывание и запуск учебного полигона (пошагово)

## 1. Установка VirtualBox

Скачайте и установите Oracle VirtualBox.

---

## 2. Скачивание образа Ubuntu

Скачать ISO-образ Ubuntu (рекомендуется 20.04 или 22.04 LTS).

---

## 3. Создание виртуальных машин

Создайте две виртуальные машины:

### victim

Назначение: сервер с уязвимым веб-приложением.

### analyzer

Назначение: анализ сетевого трафика и взаимодействие с приложением.

---

## 4. Настройка сети VirtualBox

Для обеих виртуальных машин:

* Тип адаптера: Host-Only Adapter или Internal Network
* Обе машины должны находиться в одной сети

---

## 5. Проверка соединения

На analyzer:

```bash
ping <IP victim>
```

Если получен ответ, сетевое соединение настроено корректно.

---

## 6. Установка инструментов (analyzer)

```bash
sudo apt update
sudo apt install wireshark -y
```

Запуск Wireshark:

```bash
sudo wireshark
```

---

## 7. Клонирование проекта (victim)

На victim:

```bash
sudo apt update
sudo apt install git -y
```

Клонирование репозитория:

```bash
git clone https://github.com/maximyka/ProjectHackWeb.git
cd vuln-lab
```

---

## 8. Установка зависимостей (victim)

```bash
sudo apt install python3-pip -y
pip3 install flask markdown
```

---

## 9. Запуск приложения (victim)

Перед запуском убедитесь, что сервер доступен по сети:

```python
app.run(host="0.0.0.0", port=5000)
```

Запуск:

```bash
python3 app.py
```

---

## 10. Проверка доступа

На analyzer в браузере:

```
http://<IP victim>:5000
```

---

## 11. Тестирование уязвимостей

### SQL Injection

```
admin' OR '1'='1
```

### Cross-Site Scripting (XSS)

```html
<script>alert(1)</script>
```

### File Upload

Загрузка произвольного файла.

### Directory Traversal

```
../../etc/passwd
```

---

## 12. Анализ трафика (analyzer)

В Wireshark:

1. Выбрать активный интерфейс (например, enp0s3)
2. Установить фильтр:

```
tcp.port == 5000
```

---

## 13. Результаты наблюдения

В трафике можно увидеть:

* HTTP GET и POST запросы
* параметры атак
* cookies
* передачу файлов
* взаимодействие клиента и сервера
