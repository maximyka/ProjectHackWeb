# Учебный полигон веб-уязвимостей

Учебное веб-приложение для демонстрации и тестирования типовых уязвимостей веб-безопасности.

Проект предназначен для студентов и начинающих специалистов в области информационной безопасности и позволяет на практике изучить, как работают атаки и как они выглядят на уровне сети.

---

## Цель проекта

Создать простую и наглядную среду, в которой можно:
- протестировать основные веб-уязвимости;
- увидеть, как формируются атаки;
- проанализировать сетевой трафик;
- понять последствия небезопасной разработки.

---

---

## Реализованные уязвимости

В приложении реализованы следующие уязвимости:

- SQL Injection  
- Cross-Site Scripting (XSS)  
- Directory Traversal  
- File Upload  
- Cookie Tampering  

Каждая уязвимость сопровождается:
- формой ввода;
- демонстрацией атаки;
- пояснением;
- учебной документацией.
