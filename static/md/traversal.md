## DIRECTORY TRAVERSAL (Path Traversal)

### Что такое Directory Traversal?

**Directory Traversal** — это уязвимость, которая позволяет злоумышленнику получить доступ к файлам вне предусмотренной директории на сервере. Если приложение позволяет пользователю указывать путь к файлу без проверки, злоумышленник может использовать последовательности `../` (обход каталогов) для доступа к конфиденциальным файлам.

### Как ею воспользоваться?

1. **Чтение конфигурационных файлов:**
```
https://example.com/download?file=../../../../etc/passwd
```
Это позволит прочитать системный файл `/etc/passwd`, содержащий информацию о пользователях системы.

2. **Доступ к исходному коду:**
```
https://example.com/view?file=../../../app.py
```

3. **Чтение файлов с учетными данными:**
```
https://example.com/files?path=../../config/.env
```
Файлы `.env` часто содержат пароли, ключи API и другие секреты.

4. **Чтение приватных файлов пользователей:**
```
https://example.com/download?file=../../../home/username/.ssh/id_rsa
```

### Что это дает злоумышленнику?

- ✓ Доступ к системным файлам (`/etc/passwd`, `/etc/shadow`)
- ✓ Кража учетных данных и ключей API
- ✓ Чтение исходного кода приложения
- ✓ Получение информации о структуре сервера
- ✓ Доступ к приватным файлам других пользователей
- ✓ В некоторых случаях — модификация или удаление файлов

### Где ошибка разработчика?

Разработчик использует пользовательский ввод как часть пути к файлу без проверки:

```python
# УЯЗВИМО
filename = request.args.get('file')
filepath = os.path.join('/var/www/uploads', filename)
with open(filepath, 'r') as f:
    return f.read()
```

Если пользователь передаст `../../../etc/passwd`, реальный путь будет `/var/www/uploads/../../../etc/passwd`, что разрешится в `/etc/passwd`.

### Как это работает на уровне кода?

Когда нормальный пользователь запрашивает `document.pdf`:
```
Базовая директория: /var/www/uploads/
Запрашиваемый файл: document.pdf
Итоговый путь: /var/www/uploads/document.pdf ✓ Безопасно
```

Но если злоумышленник запрашивает `../../../etc/passwd`:
```
Базовая директория: /var/www/uploads/
Запрашиваемый файл: ../../../etc/passwd
Итоговый путь: /var/www/uploads/../../../etc/passwd
Разрешение пути: /etc/passwd ✗ Утечка!
```

Последовательности `../` заставляют интерпретатор пути подняться на один уровень выше в иерархии каталогов.

### Реальные истории взломов

**Apache Struts (2017) - Equifax breach**
- Уязвимость Directory Traversal в фреймворке Apache Struts позволила злоумышленникам загрузить веб-шелл
- Компания Equifax не применила доступный патч в течение 2 месяцев
- Взломаны данные **147 млн человек**: номера социального страхования, даты рождения, адреса
- Убыток: $700 млн на урегулирование исков

**Magento eCommerce (2016)**
- Обнаружена уязвимость Directory Traversal в популярной платформе электронной коммерции
- Злоумышленники могли скачать критические файлы конфигурации
- Доступны были: учетные данные БД, ключи API платежных систем
- Тысячи онлайн-магазинов скомпрометированы

**WordPress (множественные CVE)**
- Несколько плагинов WordPress имели Directory Traversal уязвимости
- Позволяло скачивать бэкапы БД, конфигурационные файлы
- Пример: плагин "File Download Manager" (CVE-2018-8996)

### Как защититься?

1. **Whitelist разрешенных файлов:**
```python
# БЕЗОПАСНО
allowed_files = ['document.pdf', 'image.jpg', 'data.csv']
filename = request.args.get('file')
if filename not in allowed_files:
    abort(403)
filepath = os.path.join('/var/www/uploads', filename)
```

2. **Использование realpath() для нормализации пути:**
```python
import os
filename = request.args.get('file')
base_dir = '/var/www/uploads'
filepath = os.path.realpath(os.path.join(base_dir, filename))
# Проверка, что путь начинается с base_dir
if not filepath.startswith(base_dir):
    abort(403)
```

3. **Запрещение опасных символов:**
```python
if '..' in filename or '/' in filename or '\\' in filename:
    abort(400)
```

4. **Использование индексов вместо имен файлов:**
```python
# Вместо передачи имени файла, передавайте его ID
file_id = request.args.get('id')
file = Database.get_file(file_id)
```

5. **Правильные права доступа на файловой системе:** веб-сервер должен иметь доступ только к необходимым файлам
