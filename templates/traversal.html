Directory Traversal

Эта страница демонстрирует уязвимость Directory Traversal. Приложение позволяет открыть любой файл, который находится в папке проекта или выше по файловой системе, если сервер запускается с правами, дающими доступ к этим файлам.

Попробуйте открыть, например:

  • app.py
  • templates/base.html
  • ../database.db

Если структура проекта такая: 

/vuln_lab/
    app.py
    database.db
    templates/
то путь ../database.db поднимет вас на уровень выше.

Объяснение уязвимости

Directory Traversal — это ошибка, при которой приложение позволяет злоумышленнику передавать путь к файлу напрямую в файловую систему сервера.

Например:

?file=../database.db

Если сервер не ограничивает доступ, злоумышленник может читать конфигурации, ключи, пароли, исходный код приложения.

**Почему на твоём сайте не работает ../../app.py?** Потому что приложение читает файлы начиная из **корневой папки проекта**, где уже лежит app.py. Физически нет папок выше, которые содержали бы другие файлы приложения.

В реальных приложениях Directory Traversal часто применяется так:

  • ../../../../etc/passwd — Unix
  • ..\..\..\windows\win.ini — Windows
  • доступ к логам, ключам API, исходному коду

Но работать эта атака будет только если сервер запущен из директории, над которой есть нужные файлы, и сервер имеет права на их чтение.
